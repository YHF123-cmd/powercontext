# Skill 名称：周边探索助手

## 用途和适用场景
本 Skill 用于帮助用户基于起点（如地铁站、商场）寻找周边符合特定需求的地点，并给出步行距离和预计时间的推荐。
适用场景：用户提出类似“我在杭州某地铁站，想找一家咖啡馆，步行不超过 15 分钟，推荐最多 3 家，优先近一点的”的需求。

## 使用高德工具查询与筛选步骤
1. **地点搜索**：提取用户需求中的起点、地点类型（如咖啡馆、餐厅、公园）、以及限制条件。调用高德 MCP Server 的地点搜索能力，查询起点附近的候选地点。
2. **步行路线规划**：针对初步筛选出的候选地点，调用高德 MCP Server 的步行路线规划能力，获取从起点到每个候选地点的真实步行距离和预计耗时。
3. **筛选与排序**：
   - 剔除步行时间超出用户限制（如 15 分钟）的地点。
   - 按照用户的偏好（如“优先近一点”）对符合条件的地点进行升序排列。
   - 选取排名前 N（如最多 3 个）的地点作为最终推荐结果。

## 回答格式与异常处理

**推荐结果格式示例**：
| 地点名称 | 地址 | 预计步行距离 | 预计步行时间 | 推荐理由 |
| :--- | :--- | :--- | :--- | :--- |
| 星巴克(XX店) | XX路XX号 | 350米 | 5分钟 | 步行距离最近，符合您优先近一点的需求。 |

**异常处理**：
- 如果符合条件的地点数量不足：如实说明数量不足，并说明原因（如“周边步行 15 分钟内仅找到 1 家咖啡馆”）。
- 如果查询失败或未找到任何结果：如实说明情况，可建议用户放宽条件（如增加步行时间或更换地点类型）。
- 对于缺少依据的信息（如安静程度、排队情况、营业状态等）：必须标注“未核实”，绝不编造。
